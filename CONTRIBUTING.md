# certificado de desenvolvedor de origem e licença

as contribuições para este repositório estão sujeitas ao individual/corporate contributor license agreement, dependendo de em nome de quem a contribuição é feita:

- ao enviar contribuições de código como um individual para esse repositório, você concorda com a [individual contributor license agreement](https://docs.encore.com/legal/individual_contributor_license_agreement/)

- ao enviar contribuições de código como uma corporação para esse repositório, você concorda com a [corporation contributor license agreement](https://docs.gitlab.com/ee/legal/corporate_contributor_license_agreement.html)

- _este aviso deve permanecer como o primeiro item no arquivo `contributing.md`._
